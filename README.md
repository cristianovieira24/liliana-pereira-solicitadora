# Liliana Pereira — Solicitadora

Conceito independente de website institucional para Liliana Pereira, Solicitadora na Guia, Pombal. O projeto foi construído a partir de informação profissional pública e não representa, nesta fase, o website oficial.

## O que inclui

- página editorial responsiva para computador, tablet e telemóvel;
- fotografias profissionais integradas na identidade visual pública;
- áreas de intervenção em formato interativo;
- percurso de atendimento;
- contacto direto por telefone e email;
- compositor de mensagem que abre o WhatsApp sem guardar dados;
- animações de entrada, movimento subtil com o rato e alternativa para movimento reduzido;
- bloqueio de indexação enquanto for um conceito de apresentação.

## Desenvolvimento

```bash
npm run install:ci
npm run dev
```

## Verificação

```bash
npm run lint
npm test
```

## Publicação

O projeto preserva o fluxo Vinext/Sites e inclui também `npm run vercel-build` para publicação futura na Vercel. Antes de uma publicação oficial, confirmar todo o conteúdo com a profissional e rever `PROJECT_NOTES.md`.
